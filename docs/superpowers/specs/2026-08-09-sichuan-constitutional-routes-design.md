# 四川双路线：清政宪政与社会主义两院制

## SIC：清政系宪政试验

- 四川是清政系的政治、经济与社会改革试验田。其既有设定强调民权、产权保障、社会调查、整顿官僚和限制军队参政。
- 保留大明皇室，但以《四川基本法》、责任内阁和议会约束君权；全国统一后的暂定国号为“大明立宪国”。
- 沿用 `SIC.gongye` 与 `SIC.minzhong`：数值越高表示产业危机与民众不满越严重。新增清政系影响力与宪政进程。
- 国策解锁改革阶段；“四川新政”决议处理调查、预算公开、土地权益、军政关系；“宪政统一”决议提供渗透与战争目标。

## SCG：社会主义多党两院制

- SCG 建立在社会主义宪法内的多党制；合法党派共同承认革命成果与社会主义基本制度，只在经济、农业、军队和中央—地方关系上竞争。
- 人民大会按选区与人口组成，负责预算、普通法律和政府信任案；政党会保障合法社会主义政党的基础席位，复核法律、计划与高级任命。
- 沿用既有五个社会主义意识形态槽位，分别表现大同党中派、农工社会党、大同党左派、同产公会工会派和同产公会组织派。
- 新增人民授权、党际协调、战后重建三项变量；“两院政治”与“战后重建”决议产生周期性取舍；全国统一后两院升格为全国制度。

## 实现范围

- 先实现可游玩的制度主干：国策、决议、变量、动态国家精神、统一终局触发、事件和本地化。
- 用静态 Python 校验脚本验证必要 ID、引用和大括号平衡；不在第一版引入自定义议会 GUI。
- 保留已有 SIC 危机、SCG 起义、经济和军队国策；新增内容通过前置条件接入，避免覆盖用户已有改动。
