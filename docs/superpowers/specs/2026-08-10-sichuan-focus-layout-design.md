# 四川国策树：无交叉重排与图标

## 目标

重排 SIC 清政系与 SCG 革命政府新增国策，使其脱离原有树的密集区域；所有新增前置线仅从上方连向下方，不与原树节点或新增节点交叉。为所有新增国策指定项目及基础游戏已经存在的通用图标，不增加美术资源。

## 空间规则

- 保持现有国策效果、前置关系、解锁条件和成本不变。
- 新节点位于原树左侧空白区。SIC 使用中轴 `x = 7`，SCG 使用中轴 `x = 6`。
- 有两条平行分支时，分别放在中轴左右各两格；汇合节点回到中轴。
- 每个新增节点的 `y` 坐标大于其所有新增前置节点，杜绝向上连接线。
- SIC 的首个新节点在 `(7, 7)`，SCG 的首个新节点在 `(6, 7)`。它们从原有根节点向左下进入空白区；之后所有线路都在各自空白区内向下延伸。
