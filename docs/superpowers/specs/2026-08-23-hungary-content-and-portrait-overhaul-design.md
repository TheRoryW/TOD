# 匈牙利内容、将领与肖像整修设计

## 目标与边界

本次整修以“1918 年独立后、拥有多瑙河地区影响力的架空匈牙利”为叙事基调。交付内容分为两部分：可直接游玩的脚本修复，以及供美工制作的肖像交接工作簿。

范围仅限匈牙利内容，不覆盖仓库中其他国家已存在的未提交改动。

## 国策、事件与效果

### 修复原则

- 保留已有国策树的路线、坐标和前置关系，不重排国策树。
- 每个新增事件必须由具体国策、已有状态或既有事件触发；事件选项必须产生可见的游戏效果。
- 不为每个国策机械添加弹窗。新增叙事集中在会改变玩法、路线选择或国家方向的关键节点。
- 所有实际调用的匈牙利事件、事件选项及效果提示均同时提供英文和简体中文文本。
- 对空 `completion_reward`、只有提示却没有效果、无效目标、重复叠加奖励和未解析图标进行逐项修复。

### 新增或补强的叙事节点

1. **右翼内阁改组**：大选后依次任命政府首脑、外交部长和经济部长；每一项选择对应其所属顾问槽位并影响后续政府风格。
2. **经济复苏与久尔计划**：在经济改革、工业研究和多瑙河经济带节点之间加入“优先基础设施、军工或民生”的选择；奖励采用建设速度、民用/军用工厂、稳定度或政治点数的有限组合。
3. **民族政策与边疆整合**：在少数民族、斯洛伐克、罗马尼亚、摩尔多瓦和克罗地亚相关国策中增加外交妥协、自治整合或强硬治理的后果，避免只给静态修正。
4. **东墙与巴尔干外交**：东墙、友好关系和巴尔干介入节点使用受邀国实际关系、阵营与战争状态作为条件；邀请、拒绝和战后安排都有本地化的结果说明。
5. **军队现代化**：陆军重组、装甲、空军协作及海军建设节点分别提供一项规模受限的编制、经验、研发或角色解锁效果，并通过事件交代军官团与多瑙河海军的形成。

### 已确认的现有修复

- 右翼“政治调整”事件链 13→14→15 已改为真正任命对应部长，并补齐双语文本。
- “联合飞机研发”中匈牙利的航空研发奖励已移出 `every_country` 循环，确保只获得一次；每个友好参与国独立选择是否接受自己的奖励。
- 四个缺失的匈牙利精灵已补齐定义并指向存在的纹理资源。

## 架空匈牙利军官团

### 名单规则

- 所有活跃的匈牙利陆军、空军和海军将领必须使用匈牙利本土军官或合理的奥匈遗产人物。
- 不能保留 `HUN_` 前缀下的捷克、斯洛伐克或捷克斯洛伐克角色、`GFX_Portrait_czechoslovakia_*`、`GFX_idea_CZE_*`，以及对应的 CZE 肖像路径。
- 以原版匈牙利角色结构为模板：将领以 `corps_commander`、`field_marshal` 或 `navy_leader` 角色呈现，顾问使用正确的顾问槽位与 `idea_token`；不再用纯顾问条目伪装军队将领。
- 保留并强化已有的匈牙利核心军官，例如奥雷尔·施特龙费尔德、米克洛什·霍尔蒂及原版匈牙利军官团中的本土人物。其特质、技能和解锁条件根据架空路线重新分配，不直接复制原版数值。
- 右翼、民主、左翼三条政治路线各保留至少一位具有叙事关联的可用军官；共同的职业军官团可服务所有路线。

### 数据改造方式

1. 先建立当前角色清单，标记本土、奥匈遗产、捷克复制、通用占位肖像和缺失/非标准肖像。
2. 从活跃的角色、历史招募和国策解锁中剔除捷克复制将领；不删除与其他国家内容仍有关联的定义，除非它确实由匈牙利招募或国策引用。
3. 为替代人员补齐角色、特质、技能、肖像 token 和招募入口；每名新将领都有明确兵种定位，避免多名同质的“全能将军”。
4. 更新国策与历史文件中的 `recruit_character`、解锁效果和本地化，使重做名单实际可获取。

## 肖像与美术交接

### 修复原则

- 游戏脚本只引用已存在且可加载的资源；在美工新图交付前不把引用切换到不存在的文件。
- 当前国家领导人中，直接引用 PNG/JPG 的肖像被标记为需要制作 DDS；已有合规 DDS 且画面可用的资源保留。
- 需要替换的捷克肖像、通用占位肖像、缺失文件、非 DDS 文件和不合适的尺寸都会进入美术清单。

### Excel 交付

工作簿保存至桌面，包含以下工作表：

1. **肖像问题总表**：角色 ID、角色类型、当前路径、文件格式、尺寸、问题类型、建议输出文件名、重绘说明和嵌入预览图。
2. **国家领导人**：所有匈牙利国家领导人及其肖像状态、架空路线、保留/重绘建议。
3. **军队将领重做**：现有角色来源、保留/替换/移除建议、推荐兵种定位、路线可用性和肖像需求。
4. **美工规格**：DDS 文件格式、目标路径、命名、透明通道与大/小肖像需求；不包含游戏脚本修改。

错误或需要重绘的现有图片以缩略图嵌入对应行，方便美工直接核对。

## 不在本次范围内

- 不重绘或生成国家领导人、将领肖像；该工作由美工依据 Excel 执行。
- 不修改捷克斯洛伐克本国内容。
- 不改变匈牙利既有的国家地图、国策布局或其他国家的阵营逻辑，除非该逻辑是匈牙利脚本的直接错误。
