# 四川后期玩法重构设计

## 目标与边界

本轮只重构四川两条路线的后续玩法：SIC 从清政系宪政试验开始，SCG 从“革命成功”开始。以下内容保持原有玩法、触发条件和效果，不作重写：

- SIC 的产业崩溃、民众不满、川内局势 GUI、危机决议和 SCG 起义触发；
- SCG 的成都起义、各地区起义决议、地方 OOB、全川内战与革命胜利判定；
- `SCG_zhangwochengdujushi` 与 `SCG_gemingchenggong` 在 `(25,1)` 依靠旗标进行的阶段替换；
- ROC/SRC 对四川发出邀请后的“接受—反向邀请—双方均拒绝—可能开战”原则，以及 ROC 50/50、SRC 30/70 的首轮 AI 权重。

不提交、不推送、不上传 Git。保留工作区内用户已有改动。

## 总体结构

两条路线采用镜像式五阶段节奏：

1. 前期危机或内战（受保护，不修改）；
2. 四川制度定型；
3. 制度驱动的经济、重建和军队政策；
4. 与其他中国政权协商或战争整合；
5. 通过大明内战“全国统一”决议完成国家建制。

两棵树的新增与重排节点只从上向下连接。允许互斥阶段共用坐标，但同屏节点不得重叠；全国路线不得从较低的地方宪法节点向上回接。

## SIC：清政系试验田与大明君宪帝国

### 制度定位

四川是清政系的政治、经济和社会试验田。国体保留大明皇统，政体实行议会选举、责任内阁、预算公开、产权保护、地方自治和军队国家化。最终国号为“大明君宪帝国”；其制度实质是以君主为国家象征、以内阁和议会行使政治权力的君宪共和国。

### 核心资源

- `SIC.qingzhengxi`：清政系可以投入改革的政治组织力；
- `SIC.xianzheng`：宪政制度完成度；
- `SIC.gongye` 与 `SIC.minzhong`：沿用前期危机变量，后期改革仍会受产业和民生状态影响。

清政系组织力不再与宪政进度同时无成本增长。关键改革决议消耗组织力、提高宪政进度，并设置一次性法案旗标。国策负责提出议程，决议负责落实法案；《四川基本法》必须在调查、预算、产权和军政四项改革落实后才可通过。

### 后期流程

- “清政系治川试验”在前期根国策完成且川内危机处于可控区间后开放；
- 社会调查、预算审计、产权确认、军队退出党争形成两列对称改革；
- 《四川基本法》后建立省咨议会、责任内阁与君权宪法化；
- “四川模式”将试验性动态修正替换为稳定国家精神；
- 全国阶段先召开制宪派大会，再开放与 ROC/SRC 的合并谈判及对其他割据政权的政治/军事整合；
- 统一条件满足后完成全国宪章，最后由 `MNG_chongjiandaming_decision` 触发建国事件和“大明君宪帝国”国号。

## SCG：社会主义多党双院制

### 制度定位

SCG 保留社会主义基本制度和五个合法社会主义党派。人民大会按人口、选区和群众组织组成，掌握预算、普通立法与政府信任；政党会代表合法社会主义政党，负责复核法律、长期计划和高级任命。人民委员会必须同时取得两院信任。

### 核心资源

- `SCG.renmin_shouquan`：人民大会授权；
- `SCG.dangji_xietiao`：政党会协调；
- `SCG.chongjian`：战后重建进度。

两院值限制为 0–100。高值不是唯一目标：日常议政会消耗授权与协调，周期性议事压力会降低两项数值，玩家需通过大会、党际协商、修正案和信任投票维持制度。宪法门槛设计为必须至少操作一次决议，不能只靠必经国策自动越过。

### 后期流程

- “革命后第一次会议”紧接革命成功，初始化两院与重建系统；
- 多党社会主义后对称建立人民大会和政党会，再汇合至两院议事规则、责任人民委员会和《四川社会主义宪法》；
- 五项重建预算均为一次性，任选四项即可完成主要重建，避免强制清单；
- 旧经济国策整理为国有计划、工农协调、合作改造和社会主义市场四套政策组合，关键节点受两院条件约束；
- 人民军路线整理为民兵体系与职业化人民军两翼，保留原有图标和主要动态修正；
- 全国阶段通过政党会议、工农联络、全国人民军和制宪代表大会推进，最终由全国统一决议建立“中华社会主义共和国”。

## 全国整合

SIC/SCG 与 ROC/SRC 的谈判同一时间只能进行一场。邀请仍要求接壤且未交战：

1. 对方接受则并入发起方；
2. 对方拒绝则向发起方提出反向合并；
3. 发起方接受则并入对方；
4. 双方均拒绝才设置谈判破裂旗标并开放战争决议。

每条事件链结束时清理“谈判进行中”旗标。所有成功合并调用统一整合效果，处理吞并、将领国籍和后续统一状态，避免仅执行裸 `annex_country`。

四川国策终局与大明内战全国统一决议使用同一套割据政权清单。SIC/SCG 使用全国统一决议时必须已经完成各自全国制宪国策，不能绕过路线。
